22 bundled original synthesized Ogg reaction effects are installed in sfx/ for immediate playback.
They are NOT the third-party Freesound recordings in docs/REACTION_AUDIO_CATALOG.md.
For optional CC0 tracks/jingles run npm run audio:fetch; for real recorded reaction sound
replacement, download the corresponding CC0 originals and run npm run audio:reactions.
The host/presenter must enable browser audio (or interact with the page) if autoplay is blocked.
